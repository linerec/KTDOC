## 1. 사이트 한 줄 소개

**"미국 뉴저지에 있는 한국 전통 무용단 춤누리(KTDOC)를 알리고, 단원들이 함께 활동을 운영해 나가는 공식 홈페이지"**

이 사이트가 해야 할 큰 일 4가지:

1. **알리기** — 우리 단체와 활동을 외부에 보여주기 (공연 의뢰자, 학생 학부모, 언론 등)
2. **운영하기** — 단원들에게 공연 일정·자료·공지를 전달하기
3. **남기기** — 2008년부터의 공연 기록을 차곡차곡 모아두는 아카이브
4. **연결하기** — 한국어/영어/일본어/중국어 사용자 누구나 접근 가능하게

## 2. 사이트를 사용하는 사람들 (3그룹)

| 그룹 | 누구인가 | 사이트에서 주로 하는 일 |
|---|---|---|
| **방문자** | 학부모, 공연 의뢰자, 일반 관람객, 언론 | About/Program/Gallery 둘러보기, 문의하기 |
| **회원** (단원) | 가입 승인을 받은 단원·학생 | 일정 확인, 공연 자료 다운로드, 내부 공지 보기 |
| **관리자** | 원장님, 부원장 | 모든 글·사진·일정·회원 관리 |

> **[확인 필요]** "회원" 안에 등급을 나눠야 할까요?
> 예: `정단원 / 연수생 / 강사` 처럼 구분하면 자료 공개 범위를 다르게 할 수 있습니다. 처음엔 한 종류로 시작하고 나중에 나누는 것도 가능합니다.

## 3. 모든 페이지에 공통으로 들어가는 기능

### 3.1 다국어 (4개 언어)

- 한국어 / English / 日本語 / 中文 — 사이트 어디서든 우측 상단에서 언어 전환 가능
- 처음 방문 시 **브라우저 언어를 자동 감지**해서 표시 (한국 IP는 한국어, 미국 IP는 영어 등)
- 한 번 직접 선택하면 그 선택을 기억함
- 모든 메뉴, 버튼, 페이지 본문이 4개 언어 모두 번역됨

> **[확인 필요]**
> - 4개 언어 모두 처음부터 오픈할까요, 아니면 **한국어/영어 먼저 → 일본어/중국어 나중에** 단계적으로 열까요?
> - 일본어/중국어 번역은 누가 검수해 주실까요? (자동번역으로만 둘 수도 있고, 사람 검수를 거칠 수도 있습니다)

### 3.2 관리자가 화면에서 바로 글 수정

- 관리자가 로그인한 상태에서 사이트를 보면, **수정하고 싶은 문장을 클릭 → 바로 그 자리에서 수정 → 저장** 가능
- 일반 방문자에게는 보통 사이트로만 보임
- 사진도 같은 방식으로 교체 가능 (사진 클릭 → 새 사진 업로드)

> 이 방식의 장점: 별도의 관리자 페이지를 들락날락할 필요 없이, **눈에 보이는 그대로 고칩니다**. (워드 문서 고치듯이)

### 3.3 모바일/태블릿/PC 자동 대응

- 휴대폰으로 봐도, 아이패드로 봐도, 노트북으로 봐도 자동으로 화면 크기에 맞춰 보기 좋게 정렬됨
- 휴대폰에서는 메뉴가 햄버거(≡) 버튼 안으로 들어감

### 3.4 검색엔진 노출 (SEO)

- 구글, 네이버, 다음 등에서 "한국 전통 무용 뉴저지", "Korean traditional dance NJ" 등으로 검색하면 우리 사이트가 잘 나오도록 설정
- 페이지마다 미리보기 이미지·설명문이 잘 나오도록 (카카오톡·페이스북에 링크 붙여 넣었을 때 예쁘게 미리보기됨)

### 3.5 헤더/푸터(모든 페이지 위·아래)

- **상단**: 로고, 메뉴(About / Program / Gallery / Upcoming Event), 언어 전환, 로그인 버튼
- **하단**: 로고, 인스타그램·유튜브 링크, 주소·연락처, 저작권 표기

## 5. 홈(메인) 화면

방문자가 처음 들어왔을 때 **"이 단체가 뭐 하는 곳이구나"를 5초 안에 이해**할 수 있어야 합니다.

홈 화면에 들어갈 것들 (위에서 아래 순서대로):

1. **큰 메인 이미지 또는 영상** — 대표 공연 사진 또는 짧은 공연 영상 (소리 없이 자동 재생)
2. **단체 한 줄 소개** — 예: "미국 뉴저지에서 한국 전통 무용의 아름다움을 잇는 춤누리무용단"
3. **다가오는 공연 미리보기** — 가장 가까운 공연 1~2개를 카드 형태로
4. **About 짧은 소개 + "더 보기" 버튼** — About 페이지로 연결
5. **최근 갤러리** — 최근 공연 사진 4~6장
6. **인스타그램 피드** (선택) — 인스타그램 최신 게시물 자동 표시

> **[확인 필요]**
> - 메인 이미지로 쓸 **대표 사진/영상**이 있으신가요? 없다면 어떤 분위기를 원하시는지 알려 주세요.
> - 한 줄 소개 문구는 원장님께서 직접 정해 주시는 게 가장 좋습니다. (한국어/영어 둘 다)

- **어떤 수업이 있는지 목록** (예: 살풀이, 태평무, 부채춤, 어린이반 등)

  - 대상 (어린이/청소년/성인, 입문/중급/고급)

  - 대표 사진/영상
  - 수업 내용 설명
- **수강 신청/문의 버튼** — 누르면 신청 폼이 열림 (이름·연락처·관심 수업 입력 후 제출 → 관리자 이메일로 발송)

### 7.2 관리자 기능

- 새 프로그램 추가/수정/삭제
- 수업 일정 변경
- 모집 중 / 모집 마감 표시 토글

> **[확인 필요]**
> - 현재 운영 중인 **프로그램 목록**을 알려 주세요. (수업명, 대상, 시간, 수업료)
> - 수강 신청은 **사이트에서 직접 받기** vs **이메일/전화로만 받고 사이트는 정보 안내만** 중 어느 쪽을 원하시나요?
> - **온라인 결제**도 받을까요? (수업료를 사이트에서 카드로 결제) — 이건 처음엔 빼고, 1년 정도 운영해 보고 추가하는 걸 추천드립니다.

## 8. Gallery — 공연 갤러리

### 8.1 방문자(누구나) 볼 수 있는 화면

- **연도별로 묶인 공연 목록** (2026, 2025, 2024, ... 2008)
- 연도 필터, 카테고리 필터(경연대회/축제/기업행사/자체공연 등), 검색창
- 공연 카드: 대표 사진 + 날짜 + 제목 → 클릭하면 상세 페이지
- **공연 상세 페이지**:
  - 제목, 날짜, 장소, 카테고리, 설명
  - 포스터 이미지
  - 사진 갤러리 (클릭하면 크게 보기)
  - 유튜브 영상 (있으면 임베드)
  - 이전 공연 / 다음 공연 이동 버튼

### 8.2 관리자 기능

- 새 공연 추가 (제목·날짜·장소·설명·카테고리)
- 사진 여러 장 한번에 업로드 (드래그&드롭)
- 유튜브 영상 링크 붙여넣기
- 공개/비공개 전환 (작업 중인 글은 비공개로 두고, 다 되면 공개)
- 대표 공연 지정 (홈 화면에 보일 1~2개)

> **[확인 필요]**
> - 갤러리에 일부 사진을 **회원 전용**으로 둘 필요가 있나요? (예: 단원 단체 사진은 회원만)
> - 영상은 **유튜브에 먼저 올린 후 링크만 가져오기** 방식으로 가도 될까요? (이게 사이트가 가벼워지고 관리도 쉽습니다)

## 9. Upcoming Event — 다가오는 공연·행사

### 9.1 방문자가 보는 화면

- **달력 보기 / 목록 보기** 전환 가능
- 각 행사 카드: 날짜, 제목, 장소, 짧은 설명
- 클릭하면 상세 페이지: 자세한 설명, 포스터, 티켓 정보(있다면), 위치 지도
- (외부 행사인 경우) 티켓 구매 사이트로 연결되는 버튼

### 9.2 회원(단원)이 추가로 보는 화면

> 회원이 같은 공연 페이지에 로그인한 채로 들어가면, 일반 방문자에게는 안 보이는 **단원 전용 정보**가 추가로 표시됩니다.

단원 전용 정보 예시:
- 집결 시간 / 장소 / 차량 안내
- 의상·소품 준비물 체크리스트
- 무대 진행 순서
- 음원·반주 파일 다운로드
- 안무 연습 영상
- 비상 연락처
- 출석 체크 (참석 / 불참 / 미정)

### 9.3 관리자 기능

- 새 행사 등록 시 단원에게 **자동 이메일 발송** ("○월 ○일 ○○ 공연이 등록되었습니다")
- 단원별 출석 현황 한눈에 보기
- 단원 전용 자료(파일·영상) 업로드

> **[확인 필요]**
> - 단원 출석 체크가 필요한가요? 필요 없다면 빼겠습니다.
> - 행사 등록 시 자동 메일을 **모든 단원에게 일괄 발송**할까요, 아니면 **해당 공연에 참여하는 단원만 골라서** 발송할까요?

## 10. 회원가입 & 로그인

### 10.1 회원가입 흐름

```
[가입하기] 클릭 →  이름·이메일·비밀번호·소속(단원/연수생) 입력
                →  "가입 신청 완료. 관리자 승인 후 로그인 가능합니다" 안내
                →  관리자에게 알림 이메일 발송
                →  관리자가 [승인] 또는 [거절] 클릭
                →  신청자에게 결과 이메일 자동 발송
                →  승인되면 로그인 가능
```

이렇게 한 단계 승인을 두는 이유: **실제 단원만 단원 자료에 접근**할 수 있게 하기 위해서.

### 10.2 로그인

- 이메일 + 비밀번호로 로그인
- "비밀번호 찾기" → 등록한 이메일로 임시 비밀번호 발송 (또는 재설정 링크)
- (선택) **구글 계정으로 로그인** — 별도 비밀번호 없이 구글로 한 번에

### 10.3 내 정보

로그인한 회원이 자기 페이지에서 할 수 있는 것:
- 이름·연락처·프로필 사진 수정
- 비밀번호 변경
- 알림 이메일 수신 여부 설정
- 회원 탈퇴 신청

> **[확인 필요]**
> - 구글 로그인을 추가할까요? (사용자에겐 편하지만 셋업이 약간 더 필요합니다)
> - 가입 신청서에 **추가로 받고 싶은 정보**가 있나요? (예: 무용 경력, 거주 도시, 비상 연락처)

## 11. 회원 전용 화면 (로그인 후 보이는 영역)

로그인하면 메뉴 우측에 **[내 페이지]** 버튼이 생기고, 누르면 회원 전용 화면이 열립니다.

### 11.1 내 페이지 구성

| 영역 | 내용 |
|---|---|
| **대시보드(첫 화면)** | 다가오는 내 공연 일정, 새 공지, 새 자료 알림 |
| **내 일정** | 내가 참여하는 공연·연습 일정 캘린더 |

## 12. 관리자 대시보드 (원장님·부원장 전용)

`ktdoc.org/admin` 같은 주소로 접속해서 관리자 계정으로 로그인하면 보이는 화면.

### 12.1 좌측 메뉴 구성 (예상)

```
[홈]
[About 관리]      ← 단체 소개·인사말 등 텍스트 수정
[프로그램 관리]    ← 수업 추가/수정
[갤러리 관리]      ← 공연 기록 추가/수정
[행사 관리]        ← 다가오는 공연 등록
[회원 관리]        ← 가입 승인, 회원 목록
[자료실 관리]      ← 회원 전용 파일 업로드
[공지사항 관리]    ← 단원 공지 작성
[문의함]          ← 방문자 문의 메시지 모음
[번역 관리]        ← 4개 언어 번역 일괄 수정
[통계]            ← 방문자 수, 인기 페이지 등
[설정]            ← 사이트 기본 정보, 이메일 설정
```

### 12.2 대시보드(첫 화면)에서 한눈에

- 새 가입 신청 ○건
- 새 문의 메시지 ○건
- 다가오는 공연 ○개
- 최근 30일 방문자 수

### 12.3 모든 콘텐츠 작업의 공통 흐름

- **저장하지 않고 미리보기** 가능 (실제로 사이트에 어떻게 보일지 확인 후 저장)
- **임시저장 / 공개** 두 단계
- 잘못 지웠을 때 **휴지통**에서 30일 안에 복구

> **[확인 필요]**
> - 관리자 권한을 가질 사람이 **원장님과 부원장 두 분**인가요? 더 있나요?
> - 각자 권한을 다르게 줄까요? (예: 부원장은 갤러리만 수정 가능, 회원 관리는 원장만)

## 15. 단계별 오픈 제안 (Phasing)

한 번에 모든 걸 만들면 시간이 오래 걸리고 변경도 어려워집니다. **3단계로 나눠서 오픈**하는 것을 제안드립니다.

### Phase 1 — "기본 홈페이지" (외부 공개용)

먼저 **방문자에게 보여주는 부분**부터 완성합니다.

- 홈 / About / Program 안내 / Gallery / Upcoming Event
- 한국어 + 영어 (일본어/중국어는 Phase 2)
- 관리자가 모든 텍스트·사진 수정 가능
- 문의하기 폼

→ 이 정도만 있어도 명함이나 SNS에 사이트 주소를 공유할 수 있습니다.

### Phase 2 — "단원 시스템"

- 회원가입 + 관리자 승인
- 회원 전용 자료실, 공지사항
- 행사 등록 시 단원에게 자동 메일
- 일본어 / 중국어 추가

### Phase 3 — "운영 고도화"

- 공연 의뢰 폼 / 후원 받기 / 굿즈 등 (선택)
- 통계 분석
- 자동 백업 / 보안 강화

> **[확인 필요]**
> - 이 3단계 분할이 괜찮으신가요?
> - **Phase 1 오픈 희망 시점**이 언제인가요? 그에 맞춰 일정을 짜겠습니다.
