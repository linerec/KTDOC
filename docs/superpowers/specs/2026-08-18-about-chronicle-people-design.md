`docs/요구사항-초안.md` 6절에서 `/about` 구조가 이미 7개 섹션으로 합의됐고, 거기에
"연혁에 들어갈 주요 사건 목록을 정리해 주세요"라는 **[확인 필요]** 가 걸려 있었다.
8월 17일 메일이 그 답안이다. 이 설계는 새 구조를 발명하는 게 아니라 **합의된 구조를
채운다.**

현재 `/about`은 히어로 + 원장 축약 1문단, 즉 7개 중 1.5개만 있다.

### 확정된 사항

- **"오선생" = 백수경 선생.** 사이트 표기는 **백수경으로 통일**한다.
  메일 원문 직함은 "행정디렉터 및 강사(Administration Director & Instructor)"이고,
  4월 요구사항 문서의 "부원장"과 같은 인물이다. **표기는 메일 원문 직함을 따른다.**
- **공연 사진 사용 허락됨** — 촬영자 워터마크가 있는 사진 포함.

### 미해결 (진행에 지장 없음)

- **원장 인사말** 미수신 → 약력·주요 무대·수상만으로 섹션을 구성한다. 인사말이 오면

- **단원 소개** 공개 여부 미결 → 이번 범위에서 제외.

## 1. 연혁 2층 구조

### 문제

연혁 85건 중 사진이나 설명이 붙은 것은 **7건뿐**이다. 나머지 78건은 제목 한 줄이다.
현재 `EventTimeline`은 모든 항목을 **이미지 슬롯이 있는 카드**로 그리고, 이미지가 없으면
"춤누리" 플레이스홀더를 채운다. 85건을 그대로 넣으면 동일한 플레이스홀더 카드가 78개
깔리고, 각 카드는 내용 없는 상세 페이지로 링크된다.

### 해법 — 같은 연대표 안의 두 종류 줄

| | 기록층 | 연혁층 |
|---|---|---|
| 조건 | 사진 또는 설명이 있다 | 제목뿐이다 |
| 모양 | 지금의 카드 (썸네일 + 날짜 + 설명) | 한 줄 텍스트 |
| 링크 | 상세 페이지로 | **링크 아님** |
| 현재 수 | 7건 | 78건 |

**빈 상세 페이지를 만날 방법이 구조적으로 없다** — 링크가 애초에 생기지 않는다.

### 판정은 저장하지 않고 유도한다

마이그레이션을 추가하지 않는다. 다음 규칙으로 렌더 시점에 판정한다:

```
isChronicle(event) =
  설명(ko/en) 없음 AND 썸네일·포스터·첨부 이미지 없음
```

- 새 컬럼이 없으므로 원격 D1 마이그레이션이 필요 없다
- 사진이 나중에 도착해 붙는 순간 **자동으로 기록층으로 승격**된다. 관리자가 플래그를
  따로 켤 필요가 없다 — 이게 이 규칙을 저장값이 아니라 유도값으로 두는 이유다
- 판정 함수는 한 곳(`lib/events/chronicle.ts`)에만 둔다

### 연도 블록 안의 배치

한 해에 카드 1개와 줄 7개가 뒤섞이면 리듬이 깨진다. **카드를 먼저, 줄을 그 아래에** 둔다.

```
2023 ──────────────────────────
  ┌──────────┐
  │ [사진]    │  UN 세계시민교육 행사 오프닝 공연
  │           │  2023.11.13 · United Nations HQ
  └──────────┘
  그 밖의 기록                          ← 작은 라벨
  · 뉴욕한인회 한국의 날 초청공연
  · Leonia·Ramsey 공립도서관 설날 공연
  · 한미동맹 70주년 기념행사 오프닝 공연
  · 뉴저지주 우수 개인안무가상 수상
```

사진 있는 것이 주인공이 되고, 나머지는 "그 해에 이만큼 했다"는 **밀도의 증거**가 된다.
둘 다 제 역할을 한다.

### 날짜 정밀도

연혁 항목 대부분은 연도만 있다. `events.event_date`는 NOT NULL이므로:

- 연도만 아는 항목 → `YYYY-01-01`
- 월까지 아는 항목(2026년 7건) → `YYYY-MM-01`

**연혁층은 날짜를 화면에 표시하지 않으므로** 이 근사치가 노출되지 않는다. 기록층으로
승격될 때는 실제 날짜를 함께 채운다. `/performances`·`/gallery`에서도 연혁층 항목은
날짜 대신 연도만 보여준다(같은 `isChronicle` 규칙 사용).

### `/performances` 분리

81건이 들어오면 다가올 공연이 과거에 파묻힌다. 위아래로 자른다:

- **다가오는 무대** — 오늘 이후, 크게, 접히지 않음
- **지난 무대** — 연도별로 접힘, 기본은 최근 연도만 펼침

## 2. 연대표 시각 설계

이 연대표가 전해야 하는 메시지는 딱 하나다: **"18년을 한 번도 안 쉬었다."**
형태가 그 메시지를 실어야 한다.

### 유지하는 것 (이미 잘 되어 있음)

- 세로 먹선 + 스크롤 진행 빔 (`--timeline-progress`, `scaleY`만 애니메이트)
- 연도 sticky 헤딩, 연도 노드
- 정렬(과거↔현재)·종류 필터

### 더하는 것

**1) 노드 크기가 그 해의 밀도를 말한다**

연도별 항목 수에 따라 노드가 커진다. 범위는 좁게 잡는다(1.0~1.4배) — 눈치채지 못할
정도로 미묘하되, 쭉 스크롤하면 활동이 짙어지는 흐름이 몸으로 읽힌다.

```
--node-scale: clamp(1, 1 + (항목수 - 2) * 0.05, 1.4)
```

**2) 연혁층 줄의 타이포**

- 색은 `var(--text-muted)` — 카드 제목보다 한 단계 뒤로 물러난다
- 앞에 짧은 먹 대시(`–`)를 둔다. 불릿 점(·)보다 붓 획에 가깝다
- 줄 간격은 넉넉히(1.9) — 78줄이 이어져도 답답하지 않게
- **hover 효과를 주지 않는다.** 링크가 아니라는 걸 손이 먼저 알아야 한다

**3) "그 밖의 기록" 라벨**

`--soft-gold-text`, 작은 크기, 자간 넓게. 카드 묶음과 줄 묶음 사이의 경계를 만든다.
그 해에 카드가 없으면 라벨도 없다(줄만 나열).

### 지키는 제약

- 두 테마 모두에서 확인 (`npm run lint:theme` 0건)
- `prefers-reduced-motion`에서 빔은 채워진 상태로 고정 (기존 동작 유지)
- 연혁층 줄은 링크가 아니므로 탭 순서에 들어가지 않는다 — 78개의 무의미한 탭 정거장을
  만들지 않는다

## 3. `/about` 구조

```
/about
 ├ 히어로                          (그대로)
 ├ 단체 소개 (KTDOC)               ← 신설
 ├ 원장 안은희                     ← 확장
 ├ 백수경 (행정디렉터·강사)         ← 신설
 ├ 연혁 12줄 + 전체 보기 →          ← 신설
 └ 위치·연락처                     ← 신설
```

### 단체 소개

재단 소개(8/6)와 미션(5/22)을 합친다. 재단은 **한 단락 + 501(c)(3) 표기**까지만 —
기부 페이지는 이번 범위 밖이다. 다만 미국 학부모에게 501(c)(3)는 "정식 등록된 곳"이라는
신호이므로 빼지 않는다.

### 원장 소개 — 계단식

프로필 전문이 4문단이라 그대로 넣으면 안 읽힌다. 스캔하는 눈에 걸리도록 층을 나눈다:

```
[사진]  안은희
        Founder & Artistic Director

        (인사말 자리 — 미수신, 오면 여기)

        주요 무대
        카네기홀 · 링컨센터 · 케네디센터
        NBC TODAY Show · UN 본부 · 타임스퀘어

        수상
        세계국악경연대회 대상
        아시안 문화경연대회 최고안무가상·지도자상
        2023 뉴저지 Individual Artist Fellowship

        [ 약력 전체 보기 ▾ ]      ← 접어둠
```

**주요 무대 여섯 개는 문장에서 꺼내 이름만 늘어놓는다.** "카네기홀, 링컨센터,
케네디센터에서 공연했으며…"라고 쓰면 스캔에 안 걸린다. 이름만 떨어뜨려 놓으면 걸린다.

접힌 전문은 `<details>`로 구현한다 — JS 없이 동작하고, 접힌 내용도 검색엔진이 읽는다.

### 백수경 소개

원장 섹션과 **같은 골격, 한 단계 작은 크기**로 둔다. 나란히 놓으면 위계가 사라지고,
완전히 다른 모양으로 만들면 남의 집처럼 보인다. 사진 폭과 제목 크기만 줄인다.

표기: **백수경 / 행정디렉터 · 강사 (Administration Director & Instructor)**

### 연혁 요약 12줄

전체 85줄을 소개 페이지에 쏟으면 아무도 안 읽는다. 12줄만 고르되 **장소 이름이 센
것**으로 고른다 — 이 분야를 모르는 학부모도 케네디센터·UN·NBC·타임스퀘어는 안다.
