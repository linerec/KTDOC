## 첨부파일 수집 방법 (재현용)

Gmail 커넥터에는 첨부 다운로드 기능이 없어 **IMAP + 앱 비밀번호**로 받았습니다.

```bash
IMAP_USER=owenkdev@gmail.com IMAP_PASS='<앱 비밀번호 16자리>' \
OUT_DIR=docs/content/choomnoori/attachments \
  python3 <스크립트 경로>/fetch-choomnoori-attachments.py
```

`FROM choomnoori@gmail.com` 전체를 훑어 첨부를 저장하고, 같은 파일은 건너뜁니다.
앞으로 새 메일이 오면 다시 돌리기만 하면 됩니다. (앱 비밀번호 이름: `claude-work`)
