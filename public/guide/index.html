01

로그인 방법

관리자 계정으로 접속하는 방법

홈페이지를 관리하려면 먼저 관리자 계정으로 로그인해야 합니다. 로그인하면 수업 등록, 신청 확인, 공연 기록, 사진 관리 등 모든 관리 기능을 사용할 수 있습니다. 로그인하지 않은 일반 방문자에게는 관리 메뉴가 보이지 않으므로 안전합니다.

1

브라우저에서 로그인 페이지로 이동합니다

인터넷 브라우저(크롬, 엣지, 사파리 등)를 열고 주소창에 홈페이지 주소 뒤에 /login을 붙여 입력합니다.

예시: https://ktdoc.kr/login

로그인 화면 — 이메일과 비밀번호를 입력합니다

💡 자주 사용하신다면 브라우저에 이 주소를 즐겨찾기(북마크)로 등록해 두세요.
2

이메일과 비밀번호를 입력합니다

로그인 화면에서 이메일 주소와 비밀번호를 입력한 뒤, 로그인 버튼을 클릭합니다.

관리자 계정 정보는 초기 설정 때 개발사에서 안내해 드린 것을 사용합니다.

⚠️ 로그인이 되지 않으면 이메일 주소와 비밀번호가 정확한지 확인하세요. 비밀번호는 대소문자를 구분합니다.
3

로그인 후 화면을 확인합니다

로그인에 성공하면 홈페이지 메인 화면으로 이동합니다. 상단 헤더를 확인하면 다음 항목들이 새로 나타납니다.

로그인 후 홈페이지 — 상단에 Admin, Edit 버튼이 나타납니다

🛡️
Admin 버튼
관리자 대시보드로 이동합니다
✏️
Edit 버튼
편집 모드를 켜고 끕니다
👤
내 이름/이메일
현재 로그인된 계정 표시
🚪
로그아웃 버튼
사용 후 반드시 로그아웃
4

관리자 대시보드로 이동합니다

상단의 Admin 버튼을 클릭하면 관리자 전용 대시보드가 열립니다. 이곳에서 수업, 신청, 갤러리, 회원을 모두 관리합니다.

관리자 대시보드 — 전체 현황과 빠른 시작 가이드가 표시됩니다

5

사용을 마친 후 로그아웃합니다

작업이 끝나면 상단의 로그아웃 버튼을 클릭하여 로그아웃합니다. 특히 공공장소나 공유 컴퓨터에서 사용한 경우에는 반드시 로그아웃하세요.

⚠️ 비밀번호를 분실하신 경우 개발사에 연락하면 초기화해 드립니다. 비밀번호는 마이 프로필에서 직접 변경하실 수도 있습니다 (7번 회원 관리 참고).
02

수업·캠프 등록 및 공개

새 수업을 만들고 방문자에게 공개하는 방법

수업과 캠프를 홈페이지에 등록하면 방문자가 신청서를 보낼 수 있습니다. 등록한 수업은 기본적으로 비공개이므로, 내용을 다 작성한 뒤에 직접 공개로 바꿔주셔야 합니다. 한 번에 완성하지 않아도 되며, 저장해 두고 나중에 이어서 작업할 수 있습니다.

1

관리자 대시보드에서 시작합니다

상단 Admin 버튼을 눌러 대시보드로 이동합니다. 화면 하단 관리실에서 수업 및 프로그램 카드를 찾으세요.

Admin 버튼 → 관리자 대시보드 → 프로그램 관리 또는 + 새로 만들기
2

새 프로그램 만들기를 클릭합니다

+ 새로 만들기 버튼을 클릭하면 새 수업 작성 화면이 열립니다.

프로그램 관리 화면 — 등록된 수업 목록과 새로 만들기 버튼

3

수업 정보를 입력합니다

새 프로그램 작성 화면에서 아래 항목들을 입력합니다.

📝
제목
예: "2025 여름 캠프", "토요 정규반"
📄
설명
수업 내용, 대상, 수강료 등 자세한 안내
📅
기간/날짜
수업 운영 기간 또는 시작일
👥
대상
연령대, 초급/중급 등 대상 정보

모두 입력했으면 저장 버튼을 클릭합니다. 저장 후 사진을 추가할 수 있습니다.

💡 제목과 간단한 설명만 입력하고 먼저 저장한 뒤, 나중에 사진과 세부 내용을 추가해도 됩니다.
4

사진을 추가합니다

저장 후 편집 화면에서 사진 추가 버튼을 클릭합니다. 파일 선택 창이 열리면 컴퓨터에서 사진 파일을 선택하세요. 여러 장을 한 번에 올릴 수 있습니다.

ℹ️ 사진은 JPG, PNG 형식을 권장합니다. 가로 1200픽셀 이상의 선명한 사진이 홈페이지에서 잘 보입니다.
5

수업을 공개로 바꿉니다

등록된 수업은 기본적으로 비공개 상태입니다. 수업 편집 화면에서 공개 여부 항목을 공개로 변경해야 홈페이지 수업 페이지에 표시됩니다.

⚠️ 저장했다고 바로 홈페이지에 보이는 것이 아닙니다. 반드시 공개 상태로 바꿔야 방문자에게 표시됩니다.

수업 페이지 — 공개로 설정된 수업들이 이렇게 표시됩니다

6

대표 수업(강조)을 지정합니다 (선택)

수업 편집 화면에서 대표로 강조 항목을 켜면, 해당 수업이 수업 페이지 맨 위에 크게 소개됩니다. 가장 중요한 수업이나 현재 모집 중인 캠프에 사용하세요.

💡 대표 강조는 한 번에 하나만 사용하는 것이 효과적입니다. 여러 개를 동시에 강조하면 집중도가 떨어질 수 있습니다.
7

수업을 수정하거나 삭제합니다

프로그램 관리 목록에서 수업 이름을 클릭하면 편집 화면이 열립니다. 내용을 수정 후 저장하거나, 필요없는 수업은 삭제 버튼으로 지울 수 있습니다.

⚠️ 수업을 삭제하면 해당 수업으로 들어온 신청 기록도 함께 사라질 수 있습니다. 삭제 전에 신청자 정보를 먼저 확인하세요.
03

수강 신청 응대

신청자를 확인하고 연락하는 방법

수업이 공개되면 방문자가 수강 신청서를 보낼 수 있습니다. 새 신청이 들어오면 관리자 대시보드에 빨간색 알림으로 표시됩니다. 신청자 정보를 확인하고, 직접 연락한 뒤, 상태를 업데이트하여 체계적으로 관리하세요.

1

새 신청 알림을 확인합니다

관리자 대시보드에서 새 신청 N건이 빨간색으로 표시됩니다. 이것이 보이면 아직 확인하지 않은 신청이 있다는 신호입니다.

대시보드 — 새 신청이 있으면 빨간 알림이 표시됩니다

2

신청자 목록을 엽니다

대시보드의 신청자 보기 버튼 또는 좌측 메뉴의 신청 현황을 클릭합니다.

관리자 대시보드 → 신청자 보기

신청자 목록에서 이름, 연락처, 신청한 수업, 신청 날짜, 현재 상태를 한눈에 볼 수 있습니다.

신청 현황 — 신청자 이름·날짜·상태를 한눈에 확인

3

신청 상세 정보를 확인합니다

목록에서 신청자 이름을 클릭하면 상세 화면이 열립니다. 희망 시작일, 메모, 연락처 등 신청자가 입력한 모든 정보를 확인할 수 있습니다.

💡 상세 화면에서 이메일 주소나 전화번호를 클릭하면 바로 연락할 수 있습니다.
4

신청자에게 직접 연락합니다

신청서에 있는 이메일 또는 전화번호로 신청자에게 직접 연락합니다. 수업 일정, 장소, 비용 등 필요한 정보를 안내해 드리세요.

ℹ️ 새 신청이 들어왔을 때 24시간 이내에 연락하면 등록 확정률이 높아집니다.
5

신청 상태를 업데이트합니다

연락 후 신청 상세 화면에서 상태를 변경합니다. 상태는 아래 순서로 진행됩니다.

🔴 신규 → 🟡 연락함 → 🟢 확정 또는 ⬜ 거절
🔴
신규
방금 들어온 신청. 아직 확인 전
🟡
연락함
전화나 이메일로 연락을 취함
🟢
확정
수강 등록이 완료된 상태
⬜
거절
정원 초과 등 등록 불가 상태

상태를 선택 후 저장을 클릭합니다.

04

공연 기록 관리

지난 공연을 사진·영상과 함께 아카이브로 남기는 방법

무용단의 공연 기록을 사진과 유튜브 영상과 함께 홈페이지에 남깁니다. 공개된 공연은 갤러리 페이지에 연도별 타임라인으로 쌓여 무용단의 역사를 보여줍니다. 가장 내세우고 싶은 공연은 대표 공연으로 지정하면 공연 페이지 상단에 크게 소개됩니다.

1

이벤트 아카이브를 엽니다

관리자 메뉴에서 이벤트 아카이브를 클릭하면 등록된 공연·행사 목록이 나타납니다.

관리자 대시보드 → 이벤트 아카이브

이벤트 아카이브 — 등록된 공연·행사 목록

2

새 이벤트 등록을 시작합니다

관리자 대시보드 하단 관리실에서 이벤트 관리 또는 + 새 이벤트 버튼을 클릭합니다.

이벤트 아카이브 → + 새 이벤트

새 아카이브 이벤트 만들기 화면

3

공연 기본 정보를 입력합니다

새 이벤트 화면에서 아래 항목을 입력합니다.

🎭
제목
예: "제23회 정기공연", "2024 가을 특별무대"
📅
날짜
공연이 열린 날짜 (갤러리 연도 분류 기준)
🏷️
카테고리
정기공연, 특별공연, 지역행사 등
📝
설명
공연 소개, 레퍼토리, 특이사항 등

입력 후 저장 버튼을 클릭합니다. 저장 후 편집 화면에서 사진과 영상을 추가합니다.

4

공연 사진을 업로드합니다

저장 후 나타나는 이벤트 편집 화면에서 사진 추가 버튼을 클릭합니다. 여러 장을 한 번에 선택하여 업로드할 수 있습니다.

💡 첫 번째 사진이 목록과 갤러리에서 대표 이미지로 사용됩니다. 가장 인상적인 사진을 첫 번째로 업로드하세요.
5

유튜브 영상을 연결합니다 (선택)

공연 영상이 유튜브에 업로드되어 있다면, 유튜브 영상 주소(URL)를 복사하여 편집 화면의 영상 URL 입력란에 붙여넣습니다.

ℹ️ 유튜브 영상 주소는 영상 페이지에서 주소창의 URL을 그대로 복사하면 됩니다.
예: https://www.youtube.com/watch?v=xxxxx
6

사진 순서를 정렬합니다

업로드된 사진들을 원하는 순서로 드래그하여 재배치할 수 있습니다. 사진을 길게 눌러 잡은 뒤 원하는 위치로 끌어다 놓으세요.

7

공연을 공개합니다

편집 화면에서 공개 여부를 공개로 변경합니다. 공개된 공연은 갤러리 페이지에 날짜 기준으로 연도별로 자동 정렬되어 표시됩니다.

공연 페이지 — 등록된 공연들이 이렇게 표시됩니다

8

대표 공연을 지정합니다 (선택)

가장 내세우고 싶은 공연을 대표 공연(쇼케이스)으로 지정하면, 공연 페이지 상단에 크게 소개됩니다. 이벤트 편집 화면에서 쇼케이스 항목을 켜고 저장하세요.

💡 대표 공연은 최신 공연이나 가장 규모 있는 공연으로 지정하면 방문자에게 좋은 첫인상을 줄 수 있습니다.
05

편집 모드 — 글·사진 직접 수정

홈페이지 내용을 코딩 없이 바로 수정하는 방법

편집 모드는 홈페이지에 로그인한 상태에서 페이지의 글자나 사진을 그 자리에서 바로 클릭하여 수정하는 기능입니다. 코드를 다룰 필요가 전혀 없습니다. 소개 문구, 인사말, 대표 이미지 등을 직접 고칠 때 사용합니다.

1

관리자 계정으로 로그인한 상태에서 홈페이지를 엽니다

로그인 후 홈페이지 메인(사이트주소)이나 소개 페이지(사이트주소/about)로 이동합니다. 수정하고 싶은 페이지를 엽니다.

로그인 후 상단 헤더에 "Edit" 버튼이 나타납니다

2

상단 헤더의 "Edit" 버튼을 클릭합니다

상단 우측에 Edit 버튼이 있습니다. 클릭하면 버튼이 Edit ON으로 바뀌면서 편집 모드가 활성화됩니다.

3

수정할 텍스트를 클릭합니다

편집 모드가 켜진 상태에서 수정하고 싶은 글자 부분을 클릭하면 커서가 나타납니다. 기존 내용을 지우고 새 내용을 직접 입력하세요.

소개 페이지 — 편집 모드에서 텍스트를 클릭하면 바로 수정할 수 있습니다

4

사진을 교체합니다

편집 모드에서 교체하고 싶은 이미지를 클릭하면 파일 선택 창이 나타납니다. 새 사진을 선택하면 기존 사진이 교체됩니다.

ℹ️ 홈 화면의 대표 이미지, 소개 페이지의 사진 등을 이 방법으로 교체할 수 있습니다.
5

저장 버튼을 클릭합니다

수정이 끝나면 화면에 나타나는 저장 버튼을 클릭합니다. 저장을 눌러야 변경 내용이 홈페이지에 실제로 반영됩니다.

⚠️ 반드시 저장을 눌러야 합니다. 저장하지 않고 다른 페이지로 이동하거나 브라우저를 닫으면 수정한 내용이 사라집니다.
6

편집 모드를 끕니다

수정이 모두 끝났으면 Edit ON 버튼을 다시 클릭하여 편집 모드를 종료합니다. 버튼이 다시 Edit으로 돌아오면 일반 보기 모드입니다.

💡 편집 모드는 관리자 계정으로 로그인했을 때만 보입니다. 일반 방문자에게는 이 버튼이 표시되지 않습니다.

06

이벤트·사진 관리

사진 보관함과 연도별 갤러리 타임라인 관리

갤러리는 공연(이벤트) 단위로 사진이 묶이고, 연도별로 정렬되어 표시됩니다. 사진 보관함에 사진을 모아두고, 각 이벤트에 연결하는 방식으로 운영합니다. 카테고리를 사용하면 공연 종류를 분류하여 관리할 수 있습니다.

1

갤러리 구조를 이해합니다

홈페이지 갤러리는 다음과 같이 구성됩니다.

📁
사진 보관함
아직 이벤트에 배정되지 않은 사진들이 모이는 임시 저장소
🎭
이벤트(공연)
날짜와 제목이 있는 공연 단위. 사진들이 묶임
🗓️
연도별 타임라인
공개 이벤트가 연도별로 정렬되어 갤러리에 표시됨
🏷️
카테고리
정기공연, 특별무대 등 공연 종류를 분류하는 태그

갤러리 페이지 — 연도별로 공연이 정렬되어 표시됩니다

2

사진 보관함에 사진을 업로드합니다

관리자 메뉴에서 사진 보관함으로 이동합니다. 사진 추가 버튼을 클릭하여 여러 장을 한 번에 업로드할 수 있습니다.

관리자 대시보드 → 공연·갤러리 카드 → 사진 보관함
💡 공연 사진을 촬영 후 보관함에 미리 업로드해 두면, 나중에 이벤트를 만들 때 바로 가져다 쓸 수 있습니다.
3

이벤트에 사진을 연결합니다

이벤트 편집 화면에서 사진 탭을 엽니다. 보관함에서 추가 버튼을 클릭하면 보관함의 사진을 선택하여 이벤트에 연결할 수 있습니다. 새 사진을 직접 업로드하는 것도 가능합니다.

4

사진 순서를 변경합니다

이벤트 편집 화면에서 사진을 마우스로 길게 클릭한 채 원하는 위치로 끌어다 놓으면 순서가 바뀝니다. 가장 인상적인 사진을 첫 번째에 두세요.

5

카테고리를 추가하거나 수정합니다

공연 종류를 분류하는 카테고리는 별도로 관리합니다.

관리자 대시보드 → 이벤트 카테고리

이 화면에서 카테고리를 추가, 수정, 삭제할 수 있습니다. 예: 정기공연, 특별공연, 지역행사, 초청공연 등.

6

갤러리 타임라인 확인

공개된 이벤트는 갤러리 페이지(사이트주소/gallery)에서 확인할 수 있습니다. 날짜 기준으로 연도별로 자동 정렬됩니다.

ℹ️ 이벤트 날짜를 정확하게 입력해야 갤러리 타임라인이 올바르게 정렬됩니다.
07

회원 관리

사이트 회원 목록 확인 및 프로필·비밀번호 변경

홈페이지에 가입한 사용자를 회원이라고 합니다. 회원은 일반 회원과 관리자로 구분됩니다. 회원 관리 메뉴에서 가입자 목록을 확인하고, 내 프로필과 비밀번호를 변경할 수 있습니다.

1

회원 목록을 확인합니다

관리자 대시보드에서 회원 목록 보기 버튼을 클릭합니다.

관리자 대시보드 → 회원 관리 카드 → 회원 목록 보기

관리자 대시보드 — 회원 관리 카드에서 회원 수를 확인합니다

2

회원 정보를 확인합니다

회원 목록에서 각 회원의 다음 정보를 확인할 수 있습니다.

👤
이름
회원이 가입 시 입력한 이름
📧
이메일
로그인에 사용하는 이메일 주소
📅
가입일
최초 가입한 날짜
🛡️
권한
일반 회원 또는 관리자
3

내 프로필을 수정합니다

관리자 대시보드 좌측 메뉴 또는 상단 이름 표시 부분에서 내 프로필을 클릭합니다.

관리자 메뉴 → 내 프로필

이름을 수정하고 저장을 클릭합니다. 이름은 관리자 대시보드 환영 메시지에 표시됩니다.

4

비밀번호를 변경합니다

내 프로필 화면에서 비밀번호 변경 섹션을 찾습니다. 현재 비밀번호를 입력하고, 새 비밀번호와 새 비밀번호 확인을 입력한 뒤 변경을 클릭합니다.

💡 비밀번호는 영문 대문자, 소문자, 숫자, 특수문자를 섞어 8자 이상으로 만들면 안전합니다.
예: Chodance2025!
5

관리자 권한 추가가 필요한 경우

새로운 관리자 계정이 필요하거나 기존 회원에게 관리자 권한을 부여해야 하는 경우, 개발사에 요청하시면 처리해 드립니다.

ℹ️ 관리자 권한은 홈페이지의 모든 내용을 수정하고 삭제할 수 있는 높은 권한입니다. 신뢰할 수 있는 담당자에게만 부여하세요.

자주 묻는 질문

Q

일반 회원과 관리자의 차이는?

일반 회원은 사이트에 가입만 된 상태로, 수강 신청 시 정보가 자동으로 입력되는 정도의 혜택이 있습니다. 관리자는 Admin 메뉴에 접근하여 수업·공연·갤러리·회원을 모두 관리할 수 있습니다.

Q

로그인이 안 될 때 어떻게 하나요?

이메일 주소와 비밀번호를 다시 확인하세요. 여러 번 틀렸다면 개발사에 연락하여 비밀번호 초기화를 요청하세요.
