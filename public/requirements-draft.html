1사이트 한 줄 소개

미국 뉴저지에 있는 한국 전통 무용단 춤누리(KTDOC)를
알리고, 단원들이 함께 활동을 운영해 나가는 공식 홈페이지

이 사이트가 해야 할 큰 일 4가지:

01
알리기
우리 단체와 활동을 외부에 보여주기 — 공연 의뢰자, 학생 학부모, 언론 등
02
운영하기
단원들에게 공연 일정·자료·공지를 전달
03
남기기
2008년부터의 공연 기록을 차곡차곡 모아두는 아카이브
04
연결하기
한국어 / 영어 / 일본어 / 중국어 사용자 누구나 접근 가능

2사이트를 사용하는 사람들 (3그룹)

그룹누구인가사이트에서 주로 하는 일
방문자학부모, 공연 의뢰자, 일반 관람객, 언론About / Program / Gallery 둘러보기, 문의하기
회원 (단원)가입 승인을 받은 단원·학생일정 확인, 공연 자료 다운로드, 내부 공지 보기
관리자원장님, 부원장모든 글·사진·일정·회원 관리
"회원" 안에 등급을 나눠야 할까요?

예: 정단원 / 연수생 / 강사처럼 구분하면 자료 공개 범위를 다르게 할 수 있습니다.

3모든 페이지에 공통으로 들어가는 기능

3.1 다국어 (4개 언어)

  • 한국어 / English / 日本語 / 中文 — 사이트 어디서든 우측 상단에서 언어 전환 가능
  • 처음 방문 시 브라우저 언어를 자동 감지해서 표시 (한국 IP는 한국어, 미국 IP는 영어 등)
  • 한 번 직접 선택하면 그 선택을 기억함
  • 모든 메뉴, 버튼, 페이지 본문이 4개 언어 모두 번역됨
자동 감지가 안 될 때, 기본 언어는 어느 쪽으로 할까요?

사이트가 처음 열릴 때 언어를 못 알아내면 한 가지 언어로 보여줘야 합니다.

4개 언어를 한꺼번에 오픈할까요, 단계적으로 열까요?

3.2 관리자가 화면에서 바로 글 수정

  • 관리자가 로그인한 상태에서 사이트를 보면, 수정하고 싶은 문장을 클릭 → 바로 그 자리에서 수정 → 저장 가능
  • 일반 방문자에게는 보통 사이트로만 보임
  • 사진도 같은 방식으로 교체 가능 (사진 클릭 → 새 사진 업로드)
이 방식의 장점: 별도의 관리자 페이지를 들락날락할 필요 없이, 눈에 보이는 그대로 고칩니다. (워드 문서 고치듯이)

3.3 모바일 / 태블릿 / PC 자동 대응

이 사이트의 가장 중요한 목표는
원장님과 단원·학생들이 스마트폰 첫 화면에 등록해 두고
매일매일 들여다보며 활용하는 것입니다.

그래서 모바일에서 특히 다음을 신경 씁니다:

  • 스마트폰 홈 화면에 추가하면 춤누리 전용 앱처럼 동그란 아이콘과 이름이 예쁘게 표시 (PWA 방식)
  • 아이콘을 누르면 일반 앱처럼 주소창 없이 바로 사이트가 열림
  • 모바일에서 1~2초 안에 빠르게 로딩 (느린 인터넷에서도 부담 없이)
  • 한 손으로도 조작하기 쉽게 메뉴와 버튼이 화면 아래쪽에 위치
  • 다가오는 공연 / 새 공지 / 새 자료가 홈 화면 첫 줄에 바로 보이게
  • 나이가 있으신 단원도 편하게 보실 수 있도록 글씨 크기를 충분히 크게

또한 휴대폰·아이패드·노트북·데스크탑 어디서 봐도 화면 크기에 맞게 자동 정렬됩니다.

3.4 검색엔진 노출 (SEO)

  • 구글, 네이버, 다음 등에서 "한국 전통 무용 뉴저지", "Korean traditional dance NJ" 등으로 검색하면 우리 사이트가 잘 나오도록 설정
  • 페이지마다 미리보기 이미지·설명문이 잘 나오도록 (카카오톡·페이스북에 링크 붙여 넣었을 때 예쁘게 미리보기됨)

3.5 헤더 / 푸터 (모든 페이지 위·아래)

  • 상단: 로고, 메뉴(About / Program / Gallery / Upcoming Event), 언어 전환, 로그인 버튼
  • 하단: 로고, 인스타그램·유튜브 링크, 주소·연락처, 저작권 표기

9.2 회원(단원)이 추가로 보는 화면

단원이 로그인한 채로 들어가면, 일반 방문자에게는 안 보이는 단원 전용 정보가 추가로 표시됩니다 — 집결 시간/장소, 의상·소품, 무대 진행 순서, 음원 파일, 안무 영상, 출석 체크 등.

단원 출석 체크 기능이 필요한가요?

단원이 각 공연마다 "참석 / 불참 / 미정"을 선택하면 관리자가 한눈에 봅니다.

새 공연이 등록되면 자동 메일을 누구에게 보낼까요?

10회원가입 & 로그인

10.1 회원가입 흐름

[가입하기] 클릭  →  이름·이메일·비밀번호·소속 입력
                  →  "관리자 승인 후 로그인 가능합니다" 안내
                  →  관리자에게 알림 이메일
                  →  관리자가 [승인] 또는 [거절]
                  →  신청자에게 결과 메일 자동 발송
                  →  승인되면 로그인 가능
실제 단원만 단원 자료에 접근할 수 있도록 한 단계 승인을 둡니다.

10.2 로그인 / 내 정보

  • 이메일 + 비밀번호 로그인, 비밀번호 찾기 기능
  • 회원이 직접: 프로필·연락처·비밀번호 수정, 알림 받기 설정
구글 계정으로도 로그인할 수 있게 할까요?

구글 아이디만 있으면 비밀번호 따로 만들지 않고도 로그인 가능합니다. 사용자에겐 편하지만 셋업이 약간 더 필요합니다.

가입 신청서에 추가로 받고 싶은 정보가 있으신가요?

예: 무용 경력, 거주 도시, 비상 연락처, 보호자 정보(미성년자) 등

15단계별 오픈 제안

한 번에 모든 걸 만들면 시간이 오래 걸리고 변경도 어려워집니다. 3단계로 나눠서 오픈하는 것을 제안드립니다.

Phase 1 — 기본 홈페이지 (외부 공개용)

  • 홈 / About / Program 안내 / Gallery / Upcoming Event
  • 한국어 + 영어 (일본어/중국어는 Phase 2)
  • 관리자가 모든 텍스트·사진 수정 가능
  • 문의하기 폼
  • 스마트폰 홈 화면 등록 가능 (PWA)

→ 이 정도만 있어도 명함이나 SNS에 사이트 주소를 공유할 수 있습니다.

Phase 2 — 단원 시스템

  • 회원가입 + 관리자 승인
  • 회원 전용 자료실, 공지사항
  • 행사 등록 시 단원에게 자동 메일
  • 일본어 / 중국어 추가

Phase 3 — 운영 고도화

  • 공연 의뢰 폼 / 후원 받기 / 굿즈 등 (선택)
  • 통계 분석
  • 자동 백업 / 보안 강화
3단계 분할이 괜찮으신가요?
Phase 1을 언제까지 오픈하고 싶으신가요?

대략적인 목표 일정만 알려 주셔도 좋습니다 (예: "2026년 7월", "여름 공연 전까지" 등)

16다음 단계 — 이 답변을 받은 후

  1. 아래 [저장 및 보내기] 버튼을 누르시면 답변이 메일로 정리되어 오선생에게 전달됩니다.
  2. 받은 답변을 토대로 확정 요구사항 문서를 만들고, 화면 디자인 시안을 그립니다.
  3. 디자인 시안을 다시 검토하시면, 그때부터 본격적인 개발을 시작합니다.
참고 — 현재 깃 폴더에 있는 사이트는 이번 작업 이전에 시범적으로 만들어 둔 버전입니다. 같은 단체(KTDOC)를 대상으로 했지만, 이번 신규 구축에서는 요구사항을 새로 정리한 후 처음부터 다시 만들 예정입니다. 기존 디자인 자산과 자료(연혁·이미지 등)는 재사용합니다.
